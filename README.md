# Restaurant Landing Page Project

Project Overview

This is a modern, responsive Restaurant Landing Page built using pure HTML5 and CSS3. It features an eye-catching hero section with background overlay, smooth rotation animation for food visuals, custom styled call-to-action buttons, and clean navigation menus.

• Frontend: HTML5, CSS3
• Key Elements: FontAwesome Icons, Custom CSS Keyframe Animations

The system provides a sleek, modern UI for restaurant promotion, table booking CTA, and menu navigation.

Features

• Fully responsive hero section with dynamic background image and overlay.
• Custom CSS keyframe rotation animation for main food imagery.
• Interactive navigation bar with custom button styling.
• FontAwesome icon integration for visual menu cues.
• Clean typography and attractive CTA buttons.
